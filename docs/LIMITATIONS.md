# Limitations

- Generated scaffolds require engineering completion and validation.
- Controlled-run values are not performance benchmarks.
- Current automated test coverage is not asserted by this evidence package because a fresh test report was not supplied here.
- Inherited template capabilities should not be presented as unique SaaSForge engineering without project-specific evidence.
- External source APIs and model providers create availability, quota, and behavior dependencies.
- Market/competitor judgments remain decision support, not guaranteed commercial outcomes.
